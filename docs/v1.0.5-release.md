# Kurumsal Sınav v1.0.5 sürüm raporu

Tarih: 8 Kasım 2026. Değişiklikler yerel projede uygulanmıştır. Canlı migration, seed, veri silme, GitHub push veya dağıtım yapılmamıştır.

## İşleyiş

Excel önce cihazda açılır; kayıt için yönetici onayı gerekir. XLSX boyut sınırı 5 MB, satır sınırı 2.500'dür. Önizleme ve yönetim listesi 50 satır sayfalar. Eşleşmeyen yayınevleri, hatalı tarihler ve dosya içi mükerrerler ayrı gösterilir. Arama, filtrelenen tüm satırları seçme, toplu atama, aynı Excel adına atama, satır ekleme/silme ve hariç tutma desteklenir. Yalnızca geçerli, eşleştirilmiş, hariç tutulmamış satırlar gönderilir. API ayrıca kendi doğrulamasını uygular; hatalı satır diğer doğru kayıtları durdurmaz. Veritabanındaki mevcut benzersiz yayınevi/sınıf/deneme/tarih anahtarı korunur; aynı güne farklı sınavlar eklenebilir.

API yayınevlerini ve ilgili cevap anahtarlarını toplu okur; 100 satırlık veritabanı işlemleri kullanır. Başarılı gruplar ve geçmiş sayaçları aynı transaction içinde kaydedilir. Bağlantı kesilirse tamamlanan gruplar korunur; tekrar denemede benzersiz anahtarlar çoğalmayı önler. İlerleme geçmişten gerçek tamamlanan sayılarla sorgulanır. Büyük JSON yalnızca yetkilendirilmiş takvim yolunda kabul edilir (20 MB); diğer uçların 1 MB sınırı korunmuştur. Sınır aşımı 413 döndürür. Çok uzun kapsamları olan aşırı büyük dosyalar daha küçük parçalara ayrılmalıdır.

Tam yayınevi eşleşmeleri ve daha önce yönetici tarafından hatırlanmış eşleştirmeler kullanılır. Yakın isimler yalnızca mevcut etkin yayınevlerinden önerilir; otomatik yeni yayınevi oluşturulmaz ve benzer isim kesin ilişki kabul edilmez. Seri kullanıcı tarafından onaylanır; ayrı alanda tutulur, sonradan düzenlenebilir ve sınav detayında gösterilir. Eşleştirme geçmişini değiştirmek eski sınavları değiştirmez. Yerel gerçek veritabanı okunamadığı için üretimdeki yayınevi listesi doğrulanamamıştır; seed listesinin üretim verisi olduğu varsayılmamıştır.

Eşleşmeyen satır kaydedilmez. Ekran açıkken düzeltilebilir; daha sonra devam etmek için düzenlenmiş Excel indirilir. Excel'in ek Eşleştirmeler sayfası seri bilgisini korur. Sunucuda eşleşmemiş satırlar için taslak deposu eklenmemiştir.

Geri alma sadece ilgili yüklemenin oluşturduğu, ilk kayıt zamanından beri değiştirilmemiş, cevap anahtarına bağlanmamış sınavları siler. Başka yüklemenin kayıtları, düzenlenmiş kayıtlar ve bağlı cevap anahtarları korunur; korunan adet bildirilir. Devam eden yükleme geri alınamaz. Sunucu işlem sırasında zorla durdurulursa geçmişte `processing` kalabilir; bu durumda veritabanındaki yükleme ve kayıtlar yönetici tarafından incelenmelidir.

Derslik ekleme üst düğmesi artık yalnızca odağa geçmez; özel modal ile ad/kapasite/kampüs alıp gerçek ekleme işlemini çağırır. Eklemede mevcut sözel/sayısal kayıtlar korunur. Düzenleme dolu dersliğin kapasitesini mevcut kişi sayısının altına indirmeyi ve uyumsuz kampüs değiştirmeyi reddeder. Dolu veya öğrenci sabitlenmiş derslik silinmez; önce öğrenciler taşınır.

Yeni kullanıcıya rastgele, paylaşılmayan bir ilk parola özeti atanır. Şifre kurma bağlantısının 256 bit token'ı yalnızca SHA-256 özetiyle saklanır, 30 dakika geçerlidir; tek koşullu update ile tüketilir. Kullanımdan sonra token temizlenir. Normal parola değişimi ve yönetici parola sıfırlaması da bekleyen bağlantıyı iptal eder. Bağlantıdaki token URL fragment'ındadır; sayfa açılınca adres çubuğundan temizlenir. Kurulum sayfası noindex ve no-referrer'dır. WhatsApp mesajı düzenlenebilir; gönderimi WhatsApp'ta yönetici onaylar. Token bir erişim sırrıdır; mesaj yalnızca doğru alıcıyla paylaşılmalıdır.

OG görseli `/opengraph-image` yolunda kimlik doğrulamasız PNG'dir. Mevcut favicon'un logo şekli korunur. Yerel ve lisans dosyası ekli fontlar Türkçe karakterleri destekler. Metadata mutlak `https://kurumsalsinav.com/opengraph-image`, 1200×630 ve image/png bildirir. Login robots.txt ile engellenmez; HTML noindex kuralı korunur. Girişin mevcut çalışan animasyonu/reduced-motion desteği korunmuş ve tarayıcıda doğrulanmıştır. WhatsApp'ın gerçek önbellek/önizleme kararı canlı yayından sonra kontrol edilmelidir.

## Migration

`20261108120000_v1_0_5_schedule_imports` PostgreSQL migration'ı:

- `User`: isteğe bağlı benzersiz `setupTokenHash` ve `setupExpiresAt`.
- `ExamScheduleEntry`: isteğe bağlı `importId`, `importBaseline`, `series`, `sourcePublisher` ve yükleme indeksi.
- `ScheduleImport`: kullanıcı/tarih, toplam/kaydedilen/hatalı/mükerrer sayaçları ve sonuç.
- `PublisherAlias`: normalize kaynak isim, mevcut yayınevi kimliği, isteğe bağlı seri ve değişiklik zamanı.

Eski kayıtları silen veya zorunlu alan ekleyen işlem içermez. Prisma schema diff çıktısı ile karşılaştırılmıştır. Canlı veya yerel gerçek veritabanına uygulanmamıştır.

- API TypeScript ve Web production build başarılı. Ortam değişkeni olmadan ilk Web build, mevcut `NEXT_PUBLIC_API_URL` zorunluluğu nedeniyle başarısız olmuştur; HTTPS değeri verilince geçmiştir.
- Chrome CDP tarayıcı testi: 390px panel, üç oyun kontrolleri, yılan kaydırması, kuşa dokunma, hatırlanan ses, derslik ekleme/düzenleme/silme; 2.500 satır mobil önizlemede sadece 50 DOM satırı, hatalı/mükerrer ayırma ve yayınevi önerisi onayı.
- Tarama: renk/gri/siyah-beyaz gerçek önizleme piksel kontrolü, PNG/JPEG/WebP/PDF blob çıktıları; kamera izin reddi benzetimi.
- Giriş hareketli gradient ve prefers-reduced-motion; OG HTML alanları, PNG MIME/boyutu ve görsel inceleme.
- Ana sayfa, login, takvim, değerlendirme ve PDF sayfalarında 390/768/1440px yatay taşma kontrolü başarılı.

Tarayıcıdaki dokunma benzetimi fiziksel cihaz testinin yerini tamamen almaz.

## GitHub ve cPanel için adımlar

1. Değişiklikleri ve migration SQL'ini inceleyin. `.env`, parola, anahtar, öğrenci dosyaları, `test-results`, `node_modules`, `.next` ve `dist` Git'e alınmamalıdır. Bunlar için ignore kuralları korunmuştur. Yalnızca incelenen kaynak/test/belge/font-lisans dosyalarını commit edip ayrı dal/PR üzerinden GitHub'a gönderin.
2. Canlı PostgreSQL ve dosya depolama yedeği alın. Önce ayrı bir staging PostgreSQL veritabanında eski migration durumundan yükseltme ve mevcut verilerin korunduğunu doğrulayın. `migrate reset`, `db push` ve seed kullanmayın.
3. cPanel Node uygulamalarında mevcut PostgreSQL bağlantısı, güçlü JWT anahtarı, HTTPS `WEB_ORIGIN=https://kurumsalsinav.com`, gerçek HTTPS `NEXT_PUBLIC_API_URL` ve depolama/SMTP ayarlarını panel üzerinden sağlayın. Bu ayarlar kaynak deposuna yazılmamalıdır. `https://api.kurumsalsinav.com` yerel build'de kullanılan örnek HTTPS API adresidir; gerçek yayın adresini teyit edin.
4. Node 20/22 ile `npm ci`, `npm test`, `npm run db:generate`, `npm run build` çalıştırın. Web build sırasında `NEXT_PUBLIC_API_URL` mutlaka tanımlı olsun. `npm run build` migration uygulamaz.
5. Yalnızca yayın sorumlusu tarafından onaylanan bakım penceresinde, staging doğrulamasından sonra `npm run db:migrate:deploy` çalıştırın; ardından mevcut API ve Web süreçlerini yeni sürümle başlatın. Bu geliştirme sırasında bu komut çalıştırılmamıştır.
6. Reverse proxy'nin kimlik doğrulanmış takvim POST yolunda 20 MB JSON ve uygun istek süresine izin verdiğini doğrulayın. Diğer upload sınırlarını mevcut dosya akışlarına göre koruyun. `public/fonts` ve `public/vendor` dosyalarını dağıtıma dahil edin.
7. Gerçek yöneticiyle 2.500 satırlık deneme yüklemesi, aynı dosyayı tekrar yükleme, kısmi hatalar, eşleştirme geçmişi, seçili yükleme geri alma ve düzenlenmiş kaydı koruma senaryolarını staging'de çalıştırın. Ardından davet, telefon, fiziksel mobil kamera/oyun/ses ve OG yolunu herkese açık HTTPS üzerinden kontrol edin.
8. Ana sayfa/login HTML'inde OG alanlarını ve görsel URL'sinin 200 + image/png yanıtını kontrol edin; WhatsApp önizlemesi önbelleğinin yenilenmesi gecikebilir. Uygulamanın loglarını ve kaynak kullanımını gözleyin.
