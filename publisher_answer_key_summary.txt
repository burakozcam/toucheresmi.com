Başlangıç yayınevlerini nasıl ekleyeceğiz:
- .env içindeki admin bilgileri ayarla:
  - ADMIN_EMAIL
  - ADMIN_PASSWORD
- Sonra çalıştır:
  cd "/home/burak/Masaüstü/kurumsal sinav"
  npm run db:migrate
  npm run db:seed

- Bu seed, aynı yayınevini tekrar eklememek için normalize + upsert kullanıyor. İstersen tekrar çalıştırılabilir, mevcut verileri silmez.

GitHub ve cPanel’e güvenli gönderme:
1. Branch oluştur:
   git checkout -b feature/publisher-answer-key-modules
2. Değişiklikleri ekle ve commit et:
   git add .
   git commit -m "feat: add publisher and answer key modules"
3. GitHub’a push et:
   git push origin feature/publisher-answer-key-modules
4. PR aç ve review sonrası main’e merge et.
5. cPanel tarafında:
   - repo’yu sunucuya çek
   - dependency install
   - migration uygula:
     npm install
     npm run db:migrate:deploy
     npm run db:seed
   - web/api servislerini yeniden başlat
   - sadece production TLS ve güvenli env değişkenleri ile yayınla

Not: canlı sunucuya otomatik kopyalama veya “silip yeniden başlatma” işlemi sandbox içinde yapılmadı; üretim sunucusunda, yetkili erişimle ve kontrollü deploy yapmanız doğru olur.
